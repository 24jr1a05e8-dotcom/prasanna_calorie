# Prasanna Chowdary - Calorie Calculator 🥗

A beginner-friendly Python + Streamlit project based on Project 3 of the provided Python + Streamlit Project Challenge.

## Features
- Enter age
- Select gender
- Enter height and weight
- Metric and Imperial unit options
- Select activity level
- Calculate BMR
- Estimate daily calorie requirement
- Display result clearly
- Provide simple user-friendly interpretation
- Download the result
- Colorful responsive UI
- Animated title and hero section
- No database used

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project requirement
This project uses Python + Streamlit and does not use a database.
